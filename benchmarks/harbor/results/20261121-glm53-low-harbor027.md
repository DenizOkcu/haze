# Harbor 0.27.0 — GLM-5.3, low reasoning, 2026-11-21

One serial trial per agent on `local/csv-query`, using the Z.ai Coding backend,
Docker and a 900-second agent timeout. Each container installed the latest
published agent version available on the run date. Low reasoning was requested
for every agent. These are single trials on one task, not a general ranking.

| Agent | Version | Verifier | Agent time | Input tokens | Output tokens | Tool calls |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| haze | 1.7.12 | 18/19 | 52 s | 68,474 | 2,771 | 7 |
| pi | 0.73.1 | 19/19 | 130 s | 77,331 | 8,917 | 12 |
| nanocoder | 1.32.0 | 19/19 | 449 s | 334,580 | 30,511 | 25 |
| Claude Code | 2.1.330 | 18/19 | 24 s | 52,730 | 1,362 | 4 |

No trial had a Harbor exception. Haze and Claude Code each failed
`test_sort_stability_and_utf8_byte_order`. A passing CLI exit is distinct from
a passing verifier. Agent time excludes environment setup and verification.

Haze logged low as requested and effective. Pi received `--thinking low`,
Claude Code received `--effort low`, and nanocoder was configured to send
`thinking.type=enabled` and `reasoning_effort=low` through its compatible
provider options. The provider's actual effort was not independently attested.
Protocols and token accounting vary; input totals include cache reads when
reported. The nanocoder adapter does not populate Harbor's cache-token field.

Local job names are `csv-query-<agent>-low-20261121-114050-31020` under the
gitignored `benchmarks/harbor/jobs/` directory. Raw jobs can contain sensitive
information. The separate [Harbor 0.20.0 low-reasoning run](20261121-glm53-low.md)
remains available for context.
