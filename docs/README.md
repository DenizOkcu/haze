# docs/

Static documentation site published at https://denizokcu.github.io/haze/.
The public pages are generated by Astro from `website/`. Edit that source, then
run `npm ci --prefix website` and `npm run sync --prefix website` and commit the
generated files under `docs/`. `npm run check --prefix website` detects stale
output. The sync copies only an explicit public-file allowlist and never touches
the Markdown reviews in this directory. The canonical URL defaults to GitHub
Pages; other hosts can set `PUBLIC_SITE_URL` and `PUBLIC_SITE_OUT_DIR` when
building their own artifact.

## Source of truth

The docs can drift from code unless each page names what it mirrors.
When you change behavior in one of the source files below, update the
corresponding docs page in the same PR.

| Page | Mirrors |
|------|---------|
| `index.html` | `README.md` (feature list, install, safety model) |
| `quickstart.html` | `README.md` install/usage sections; `src/cli/index.ts` CLI flags |
| `commands.html` | `src/cli/commands/commands.ts` slash-command catalog |
| `tools.html` | `src/llm/hazeTools.ts` tool catalog; `src/llm/tools/**` implementations |
| `skills.html` | `src/skills/**` and `src/llm/systemPrompt.ts` skill guidance |
| `workflows.html` | `README.md` examples and `AGENTS.md` runtime contracts |

## Release alignment

Keep the source pages’ npm version stamps and quickstart version example aligned with package metadata. Reasoning compatibility is described in `commands.html`; full transcript replay on width changes is described in `workflows.html` and the README. Historical migration plans, validation reports, and architecture reviews retain their original versions and dates.

## Regeneration

The sync generates the public HTML, CSS, JavaScript, robots.txt and sitemap.
Content is still maintained in `website/src/content/`; it is not automatically
derived from the CLI source. Use the table above as the review checklist.
